# 更新记录

## 0.1.3 — 2026-10-07

- 密码、Face ID、手机解锁和其他实际用户接管通过可用的宿主提问功能提示，首个选项原样为「已完成继续」，第二个为「暂时无法完成」。
- 提供 Default 异步提问参数示例；真实用户答复前保持待答，不将工具立即返回、默认预选或经过时间视为完成。
- 同步操作 / setup skill、认证参考和 MCP instructions；确认完成后仍从新截图继续剩余任务，不增加手机操作或观察请求。

## 0.1.2 — 2026-10-07

- 修复同时启用原版与视觉版时模型只绑定 3 个视觉工具的问题：Codex AgentPlugin 共用 64KB 工具说明预算，视觉工具被裁剪；安装脚本通过标准 `codex mcp add` 注册同一安装入口和原命名空间，恢复 15 个工具。
- 保留两插件及其 skills、截图优先操作和服务器实现。升级时自动更新标准 MCP 注册到新安装版本。
- 明确正常任务直接使用 MCP，只有具体调用不可用时才临时回退该操作，不为调用方式一致将所有操作转成 Python。
- 验收区分服务器 tools/list 与模型实际绑定，并通过不访问手机的原生 metrics 调用验证。

## 0.1.1 — 2026-10-07

- 删除整图 SHA 哈希比较、30 秒观察过期和 Runtime / 进程绑定；observation_id 改为可选记录，时钟、光标、动画变化不阻止操作。
- 删除动作前重复截图、前台与视口预检；observe 仅各读取一次截图、视口、前台 App。
- 所有手机动作支持 observe=false 跳过中间截图；launch / Home 不再依赖旧页面截图，删除固定前台轮询等待。
- batch 不再在第一个动作后强制停下；最多 20 个已知步骤连续执行并返回最终截图，未知下一页仍由模型看图定位。
- 删除 focused_input_confirmed / multiline_confirmed 执行关卡；text 为输入的唯一必填字段，换行仍由 allow_newlines 显式开启。
- 删除 XML 读取的必填理由、截图作废和读后强制再观察；XML 保持只用于页面数据读取。
- 删除 READY 后立即重复 observe、已知 App ID 的重复查询、仅因镜像运行而拒绝 READY 等额外关卡；健康配置和服务直接复用。
- 前台 App 元数据改为可选提示，最多等待 2 秒；缺失不丢弃可用截图，也不单独触发通道恢复。
- 精简 skills、代码回退与评测要求，明确工具执行完成和用户任务核验的区别。保留截图定位、用户认证接管、共享操作锁、基本参数 / 来源检查和不重放不确定动作。

## 0.1.0 — 2026-10-07

- 从 `iphone-use-wda` 0.1.4 复制为独立视觉插件，使用 `wda_vision_` 前缀与 `iphone-wda-vision-setup` / `iphone-wda-vision-use`。
- 默认观察和 READY 使用截图；所有手机动作要求当前截图的 observation_id，并返回截图供模型核验。
- 点击与长按只接受 iPhone 点坐标；滚动一次手势后停止，不使用 XML 进行元素、浮层、区域或进展判断。
- 输入依赖视觉确认的焦点；取消 selector、自动替换、提交和值回读，默认禁止换行，发送单独视觉定位及核验。
- batch 在第一个手机动作后停下，等待模型根据截图核验并确定后续目标。
- 仅为更高效的页面文字 / 列表读取保留显式 `read_page(reason=...)`；其结果不能用于操作定位或输入验收。
- 保留原插件的固定 WDA 版本、签名配置、构建、应用目录、共享 session / 操作锁、服务归属与恢复逻辑。
- 补充视觉技能、认证交接、代码回退和合成评测规范。新插件的验证另行记录，不继承原插件的测试成绩。
