# 读取与结果验收

## 列表与详情

从画面确认列表、账户、筛选、时间和展开范围。逐屏记录边界与重叠，滚动后用返回图判断方向、新增行、固定表头和浮层。无进展时检查区域与边界；没有核实覆盖范围时不称全量，未读部分不记为零。

相同名称可能对应不同记录，按实际 ID、日期、状态、金额等去重。详情按标题和关键字段核对。默认从截图读取，文字 / 列表用 XML 更高效时可直接 read_page，无需必填 reason 或读后重复截图；记录截断与缺项。XML 不用于操作目标、焦点、滚动区域或操作结果核验。

## 汇总与写入

必要加载用短等待和截图判断，不固定长等待。区分采集时间与页面给出的估值 / 成交日期，按实际账户、币种及状态汇总，避免重复相加；差额无法对账时保留未知。写入外部文档 / 数据库用对应连接器核对字段及写后结果。

## 输入与发送

从截图选择输入框，点击与输入可组成已知步骤 batch，最后看草稿。输入不自动覆盖已有内容，编辑依据实际焦点与选区。按任务核对文本、关键符号及原草稿处理结果，不用 XML value 验收。测试文案仅用于合适的合成环境。

需要换行时 allow_newlines=true，无需 focused_input_confirmed / multiline_confirmed 声明；Return 可能提交。已有发送授权时核对对象与草稿后按截图点击，检查实际结果。timeout 或结果不明先看页面，避免重发；安全输入由用户完成。

## 证据与计时

observation_id 是可选记录。已经看过的 READY、observe 或动作结果图可用于下一动作，必要结果证据按用户要求保存。工具执行完成、HTTP 成功和前台匹配不代表用户任务完成。

metrics 记录有界 HTTP / 工具计时，不包含输入文本或业务值，也不代表端到端耗时。首次部署、通道预检、手机操作和完整交付分别记录；原插件历史结果不作为视觉插件实测成绩。
