# 历史 22 项问题与本插件的处理边界

来源是 2026-10-06 的镜像任务复盘和同日 WDA 真机实验。这里只保留可复用问题，不包含个人持仓、金额、账户、设备或团队 ID。下面区分控制路径替换、工具内检查、skill 的业务验收和仍需真机验证的限制；“有机制”不代表所有 App 已验证通过。

| 编号 | 原问题 | 本插件采用的机制 | 剩余边界与验收 |
| --- | --- | --- | --- |
| I01 | Mac 镜像 App 名字精确匹配失败 | 操作通道直连真机 WDA；已知 App 通过 `wda_launch_app` 的 bundle ID 启动。 | 不依赖镜像名字；目标 App bundle ID 仍需正确，启动后验目标页。 |
| I02 | Mac AX 树没有手机内部控件 | `wda_observe` 读 iPhone 的 XCUITest 树；`wda_find` 语义定位，截图用于自绘或缺标签内容。 | WDA 也可能缺少自绘 / 保护画面的语义；固定表头遮挡不能靠 `visible` 判定。 |
| I03 | 旧状态 / 旧控制句柄失效 | 独立 session、当前 observation ID 与设备点视口；坐标动作必须引用当前观察，重连 / 接管后重新 observe。 | 异步 App 变化仍可能发生在观察后；后置条件和 screenshot 用于复核。 |
| I04 | 截图触发分享浮层 | 直接 WDA `/screenshot`，能用树定位时减少截图；skill 要求检查观察副作用。 | 尚不能保证目标 App 不检测；出现浮层后停止重复同一路径取图循环。 |
| I05 | 递归分享预览 | 同 I04；批量与滚动遇 failed / uncertain / 无进展有停止条件。 | 不自动保证安全截图；替代捕获需单独验证，不把预览金额当账户全量。 |
| I06 | 滚动区域 / 幅度不稳定 | `wda_swipe` 在设备坐标区域内先短拖动再原生 swipe，最多 2 次尝试并验证变化；`wda_scroll_find` 有界。 | 页面不同，区域需重选；指纹变化只是 UI 变化证据，不能证明新行完整。 |
| I07 | Mac scroll 不接受 pixels | MCP 只暴露真机方向与区域的 schema，避免 Mac pages / pixels 混用。 | 调用必须遵循工具真实 schema；截图像素也不能当设备点使用。 |
| I08 | 未验证 Mac drag 关闭浮层 | 优先当前浮层唯一的关闭控件；WDA 手势用于当前已观察区域。 | 关闭方式受 App 实现限制；手势完成仍须核对浮层确实消失。 |
| I09 | 登录提示过早判成永久限制 | setup/use skill 区分 WDA READY、App 登录与内容可读；保留正常登录入口，让用户完成认证再复核。 | 不绕过录屏 / 生物识别 / App 防护；密码成功一次不能证明任意限制可恢复。 |
| I10 | 真机使用使镜像中断 | WDA 不依赖镜像会话；doctor 提示镜像占用，READY 对空树与运行中的镜像组合拒绝就绪，并检查锁定状态；setup status/start 分层恢复。 | 手机锁屏、USB、测试退出和用户操作仍会影响状态；接管后需刷新观察。 |
| I11 | App 登录再次过期 | 每个新任务 / 进入 App 后检查当前登录页和目标内容，必要时用户认证。 | 不能消除服务端 session 超时；人工认证耗时单独记录。 |
| I12 | 中文搜索输入无效果 | `wda_type_text` 直接真机输入，定位字段并严格回读；短中文 / ASCII 合成测试先行。 | 某些字段或安全输入不可回读；不能凭一次成功承诺任意 App 中文可用。 |
| I13 | 长文丢字符 / 标点 | 字段回读比较完整文本；失配或无法确认就停止后续写入。 | 目标 App 的字符处理仍可变化；长文、首字符和符号要实际核对。 |
| I14 | 换行导致多条消息发送 | `allow_newlines=false`、`submit=false` 默认；草稿验收与发送分开，skill 要求检查无新消息。 | 显式允许换行可能仍引发 Return 副作用；已授权发送才执行，timeout 不盲重放。 |
| I15 | Mac 抓错窗口 / 显示器 / 坐标 | WDA 观察直接来源于设备；返回设备点视口与新 observation ID。 | 不依赖 Mac 显示器原点；方向 / 视口变化仍需新观察，图像像素和设备点可能不同。 |
| I16 | 可选平台 API 不存在 | MCP 工具固定、参数受 schema 约束；运行依赖由 doctor 诊断。 | 尚未声明支持的平台或系统版本不等于可用；以依赖探测为准。 |
| I17 | 控制 Codex 本身被拒绝 | 真机通道不需要用电脑自动化操作 Codex 或抬升镜像窗口。 | 本插件不提供 Codex 自控接口；桌面管理属于其他能力。 |
| I18 | 反复尝试没有停止条件 | batch 遇不确定即停；swipe、scroll_find、collect_list 的尝试 / 页数有上限；skill 要求无进展时改策略。 | 有界失败不等于任务完成；保存未完成范围，不再盲目加大坐标 / 手势。 |
| I19 | 数据刷新与日期口径 | 等目标 UI 稳定，再读取；skill 要求记录采集时间、估值 / 净值日期和刷新后内容。 | 工具不能判断某平台“实时”；没有日期的字段保持未知，价差不能一律归行情。 |
| I20 | 定投成功与最终确认混淆 | collect_list 给出去重与终止边界；skill 按订单、日期、状态、金额区分实扣和确认。 | 状态语义由 App / 任务决定；采集器不自动定义“实际买入”，未遍历全范围不得称统计完成。 |
| I21 | 币种 / 在途 / 外部数据库字段不匹配 | skill 保留平台、币种、日期、核实状态，禁止总额与明细重复相加；外部写入使用其专用连接器回读。 | WDA 不负责财务口径、汇率、Notion schema 或其他服务 API；未知字段不能伪造。 |
| I22 | 截图覆盖与轨迹裁剪 | 当前观察 ID 与唯一命名的截图避免同名覆盖；`wda_metrics` 保留当前进程内的有界计时，不存业务值。 | 默认最近 100 张图，旧图会清理；未自动持久保存 XML / 完整动作轨迹。重要证据应另存本机，摘要裁剪与底层根因日志仍有缺口。 |

## 速度目标与实证边界

历史一次 WDA 试验中，HTTP 外时间占 83.6%。后续对齐会话与后台日志，约 97.8% 的 HTTP 外时间属于模型请求、响应接收和生成下一次工具调用的链路；工具内部其他开销占比较小。约 5 分钟的长间隔也定位在模型响应阶段，该轮没有推理 token，不能称“思考了 5 分钟”；日志仍不能分拆服务端等待、生成停顿和传输停顿。插件以持久客户端、轻量树、按需截图和 compound tools 减少启动与往返，但不能保证解决模型服务延迟。

每轮分别报告部署、功能预检和实际业务耗时，同时核对完整度、UI 动作与工具次数。不要把 HTTP 请求数和原来的全部执行步骤直接比较，也不要只凭请求无错误宣称任务成功。

## 验证状态

[合成评测场景](../evals/cases.json)覆盖原来 18 个子用例的风险形状，避免使用真实账户与金额。mock / 单元测试可以验证 schema、坐标约束、输入保护、重试和采集边界；目标 App 的中文、截图副作用、列表覆盖与认证恢复需要真机证据。历史实验只说明某次设备与 App 组合的结果，不代表这次新插件已完成全部验收。
